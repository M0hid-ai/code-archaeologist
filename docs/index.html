🏺 Code Archaeologist

Every repository is a dig site.

Point it at any git repository and it reconstructs the story of the codebase: eras, survivors, graveyards, battlefields and a timelapse of the whole thing growing. The result is one self-contained web page.

The Museum of Express

17 years, 6,000+ commits, 380+ contributors, 500+ graves.

The Museum of Itself

Code Archaeologist excavating its own (very young) history.

 
git clone https://github.com/M0hid-ai/code-archaeologist
cd code-archaeologist && npm install && npm run build
node dist/src/bin.js https://github.com/your/repo --open
